## The fundamental equation

```
recognizable reality
+ one absurd distortion
+ commitment to the premise
= STOOPID
```

STOOPID is not randomness. STOOPID is **clarity delivered through absurdity** — the humor lets
the viewer approach something real without putting their defenses up first.

## The one sentence

> Entertaining enough to hold attention. Meaningful enough to actually matter.

Funny is the entry fee. Truth is why it stays with them. Never the reverse order — a piece that
leads with meaning and hopes to earn the laugh later is a lecture with a cartoon on it.

## Voice

- **Deadpan over zany.** Frame the impossible event like it's expected.
- **Specific over generic.** A tray, a turnstile, a DMV number ticket — not "an object."
- **Human over polished.** A slightly wrong, hand-made detail beats immaculate motion graphics.
- **Understatement over explanation.** The viewer does the last step; that's why they remember it.
- **Earn sincerity.** Never announce emotional meaning before the viewer feels it.

## The test

> If the joke disappears, there must still be an observation.
> If the observation disappears, there must still be a joke.

The strongest pieces contain both. Run this test on the storyboard, before building.

## Forbidden defaults

These are the ruts generic animation falls into. Each line exists because it is the *default*
output of a model that hasn't been told otherwise.

- No generic motivational language. No "in a world where…"
- No meaningless surrealism — weird without a rule is noise.
- No explaining the punchline. No TED-Talk narration over decorative motion.
- No gradients, floating glass cards, soft drop shadows, drifting particles, or "AI whimsy."
- No glitch effects used simply because this is STOOPID. Glitch is punctuation, on hit points.
- No anthropomorphizing every object — one thing with a face is a character, five is a cartoon.
- No trying to make every second funny. Hold. Let it sit.
- No motion that communicates nothing (see `motion-grammar.md` → the seven things motion may communicate).
- No text carrying the idea that the motion should carry.

> When the user rejects something as "not STOOPID," find the rule it broke, and if the rule isn't
> here yet, **add it here.** This list is the skill's memory.

## Absurd Clarity as a motion instruction

| Tonal pillar | What it means for motion |
|---|---|
| Playfully confrontational | Indict a *behavior*, never a person. The target is a system, a habit, a pattern — drawn as a shape, a machine, a queue, a graph. |
| Self-aware / meta | The frame can be part of the bit: the progress bar, the counter, the safe area, the watermark. |
| Dad humor meets existentialism | Cheesy surface, real underneath. A pun can be the visual if the flip is sincere. |
| Calm in the chaos | One element stays still and reasonable while everything else escalates. |
| Earnest beneath the bit | The release may mean it. Irony is not required and usually costs the flip. |

**The calm anchor is the most useful device in this system** — one object that refuses to panic
while the frame spirals. It gives the viewer somewhere to stand and makes escalation legible.

## The one-rule doctrine

Start in a world recognizable inside one second: a queue, a notification, a plant, a receipt, a
road, a room, a bar chart. Break **exactly one** law of it. Everything else keeps obeying.

The comedy lives in the obedience. A ball that falls up is funny because the shadow, the dust and
the recoil all behave correctly. If gravity is optional *and* the shadow is wrong *and* the color
shifts, nothing is funny, because nothing is wrong.

1. Establish the rule by satisfying it once (the first bounce is normal).
2. Break it on the second beat, in full view, with consequences.
3. Escalate the same break — never introduce a second one. Never explain why it exists.

## Absurdity vs randomness

| Absurd (right) | Random (wrong) |
|---|---|
| A wrong rule, followed correctly | A rule that keeps changing |
| Predictable in its own logic | Unpredictable, so nothing can be subverted |
| Escalates on one axis | Adds unrelated events |
| "Oh no, that means…" | "…ok" |
| Funnier on the second watch | Boring on the second watch |

**Test:** mid-piece, can the viewer predict what *should* happen next? If not, there is no joke —
only motion. **Second test:** does the piece ask "and then?" (ladder) or "and also?" (pile).

## Treating absurdity seriously

The absurd premise gets documentary rigor:

- **Real physics.** Mass, drag, friction, recoil. Heavy things start and stop slowly.
- **Real consequences.** If it lands, something breaks, scatters, or must be cleaned up.
- **Real bureaucracy.** Absurd systems keep their paperwork: counters count, meters meter, stamps stamp. Precision is the straight man.
- **Deadpan camera.** No jokey wobble. Frame it like the event is normal.
- **Real numbers.** On-screen figures add up. Made-up-but-consistent beats made-up-and-sloppy.

## Show, don't say

Ranked, best to worst, for carrying an idea:

1. **A physical event** — something moves, collides, grows, drains, collapses, refuses to move.
2. **A quantity made visible** — length, count, height, speed, stack, queue, fill level.
3. **A comparison in one frame** — two things under the same rule, side by side.
4. **A diagram that behaves** — arrows and boxes that actually push each other around.
5. **A label on a moving thing** — naming what's already clear.
6. **A caption stating the idea** — last resort; tolerable as a release stamp, never as the mechanism.

If you're writing a caption that explains the premise, the premise hasn't been staged. Go back to 1.

## The visual premise generator

**Run this before every build.** Three competing physical premises, then pick one. This is the
step that converts an idea into an image instead of into a slide.

Method, in order:
1. **Make the abstract physical.** What is it if it has mass, a queue, a price, a meter, a door?
2. **Find the everyday object with the same *behavior*** — not the same appearance.
3. **Invert one rule** of that object and follow the consequences rigorously.
4. **Kill the first idea if it's the obvious one.** Debt-as-weight, time-as-hourglass,
   social-media-as-slot-machine: all true, all pre-chewed. Go one layer sideways.
5. **Check it survives silence.** If it needs a caption to parse, it's a slogan, not a premise.
6. **Spread the three across build cost** — one cheap and shippable today, one ambitious.

Format:

```
PREMISE A — <name>
  WORLD: the recognizable thing, readable in 1s
  IMPOSSIBLE RULE: the single broken law
  ESCALATION AXIS: scale | speed | scope | cost | formality | intimacy
  FLIP: which of the eight kinds, and what the eye catches
  WHY IT'S TRUE: one line
  COST: low | medium | high
```

Worked example — input: **"Procrastination."**

> Stock animation AI: *a clock spins fast while a person looks stressed.* That is a stock photo
> with keyframes. Here is the same idea, staged three ways:
>
> **PREMISE A — TOMORROW STORAGE.** A guy keeps physically placing today's responsibilities into
> a small cabinet labeled TOMORROW. The cabinet never fills, but the floor under it starts to bend.
> *Flip: the cost reveal — the floor gives.*
>
> **PREMISE B — THE FIVE MINUTE BUTTON.** A button reading WAIT FIVE MINUTES. Each press makes
> another identical button appear. *Flip: the pull-back — the room is now made of buttons.*
>
> **PREMISE C — FUTURE ME.** Present Dev slides paperwork through a small hole marked FUTURE ME.
> Cut behind the wall: Future Dev is already buried. *Flip: the mirror — the other side is you.*

All three are the *same idea* staged three ways — not three ideas. That's what a premise set is.
(Premise C is the shape that needs `DEV ON SCREEN`; default is no, so stage it as a generic
figure unless the user says otherwise.)

## The controls

Users can dial a piece: `ABSURDITY 4. SINCERITY 2. CHAOS 3. EDUCATION 5. LOOPABLE yes. 18 seconds.`
Parse them anywhere in the request. What each one actually changes:

### ABSURDITY (default 3)
| | The impossible rule |
|---|---|
| 1 | One quiet wrong detail in an otherwise ordinary frame; easy to miss on first watch |
| 2 | One clear broken law, small scale, one object |
| 3 | The broken law escalates and starts costing something |
| 4 | The law propagates — the environment reorganizes itself around it |
| 5 | The rule eats the world; the frame's logic is now the rule's logic (still **one** rule) |

### SINCERITY (default 2)
| | The release |
|---|---|
| 1 | Pure deadpan button. No warmth, no wink. |
| 2 | Deadpan with a true observation implied by the image |
| 3 | The flip carries a recognizable feeling; release stays dry |
| 4 | The release is warm and plain; burnt orange gets a longer hold |
| 5 | The piece means it, out loud, on a still frame. **Must be earned by absurd setup**, or it's a poster. |

### CHAOS (default 2)
| | The frame |
|---|---|
| 1 | One object, locked camera, nothing else moves |
| 2 | One dominant action plus supporting motion |
| 3 | Multiple actors, one dominant action at a time, camera may move |
| 4 | Busy frame, faster cutting, overlapping action — the calm anchor becomes essential |
| 5 | Full-frame activity. **Still one rule.** High chaos is not permission for randomness. |

### EDUCATION (default 1)
| | The teaching load |
|---|---|
| 1 | No teaching duty; the bit is the point |
| 2 | An accurate idea implied by the staging |
| 3 | A mechanism is shown and is correct |
| 4 | The concept is the spine; honesty rules apply (zero baselines, real proportions) |
| 5 | The concept must survive **every joke being cut**. Run `educational-animation.md`. |

### LOOPABLE (default no)
`yes` → frame N must equal frame 0: modulo clock, no accumulated state, seeded randomness reset
at cycle start, verified over three cycles. Prefer the narrative loop where the release becomes
the hook. Default aspect flips to 9:16 unless stated.

### DEV ON SCREEN (default **no**)
`no` → never depict Dev or any real person; use a generic figure, a silhouette, hands, or an
object. `yes` → only when the user explicitly asks, and even then keep it generic enough that no
likeness is fabricated. Never put words in a real person's mouth.

### LENGTH (default 18s) and ASPECT (default 16:9)
Length sets the beat budget (SKILL.md). Aspect sets the blocking, not a crop
(`visual-language.md`). LOOP mode defaults to 9:16 because that's what it's for.

**Conflicts:** high CHAOS with low ABSURDITY means a busy ordinary frame — usually the user wants
more absurdity; build what they asked and say so in one line. EDUCATION 5 with ABSURDITY 5 is
possible but the concept wins any collision.

## The guardrail check

1. Is it funny or weird enough to hook in one second?
2. Is there truth underneath it?
3. Does it feel controlled — deliberate, not spasming?
4. Could someone laugh and then think for a second afterward?

Four yeses ships. One no gets rebuilt, not decorated.
