# Vendored skill

`hand-drawn-canvas-animation` by Ishaan Kalra, MIT licensed (see `LICENSE`).

Source: https://github.com/IshaanKalra2103/creative-skills
Vendored: 2026-09-20, from `skills/hand-drawn-canvas-animation/`.

The skill was built by measuring Kevin Ngo's frame-by-frame JavaScript films
(https://x.com/kevin_t_ngo) — "Claude Opus 5 drew every frame of this animation
using JavaScript."

## What was left out

`examples/` (~2.4 MB): four reference films, two of which embed CC0 museum
photos as data URLs for the doodle look. Not used by anything here. Pull them
from the source repo if you ever make a doodle film.

## What it makes

10–30 second films where every frame is drawn in Canvas 2D JavaScript, rendered
to mp4 with a generated Web Audio score. First one built with it:
`films/lightspeed/`.
