# Voice slots

Empty on purpose: no recordings ship with the film and nothing is synthesized.

Put files named after the narration ids in `../src/timeline.js` (`N01` … `N27`, as `.mp3`, `.wav` or `.ogg`) in a folder, then open the film with `?vo=<that folder>/`. Each file starts at its caption's start time, so keep each read within the caption's window.
