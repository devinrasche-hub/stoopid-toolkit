# Optional voice slots for STILL HERE

None of these recordings exist yet, and the film needs none of them: every line is already a timed caption burned into the picture.

To add a recording, save it here as `<slot>.mp3` (or `.wav` / `.ogg`), then open the film with `?vo=` pointing at this folder. From the published page at the repo root, that's:

```
stoopid_still_here.html?vo=cinematic/still-here/vo/
```

Each file starts exactly at its caption's start time and plays through the room reverb. Keep each one within its caption window.
